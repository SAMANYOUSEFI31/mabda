# صندوق نقدهای طراحی (ثبت، بدون اجرا)

جریان UI/UX به تصمیم صاحب محصول متوقف است (۱۴۰۵/۰۸/۲۵). نقدهای طراحی ممیزی بیرونی ۶۵ موردی اینجا فقط **ثبت** می‌شوند تا در دور بعدی طراحی، همراه بازخورد افراد آزمون، با هم سنجیده شوند.

**محدودیت این ثبت:** متن این شناسه‌ها نه در مخزن است و نه در پیام دستور کار؛ فقط شناسه‌ها به این رشته رسیده‌اند. پس نظر کارشناسی برای تک‌تک آن‌ها **داده نشده** و حدس زده نشده است. وقتی متن ممیزی برسد، ستون «نظر» با یکی از «موافق / مخالف / قابل بحث» و دلیل پر می‌شود.

## معیار سنجش هر نقد (وقتی متن برسد)

برچسب‌ها طبق اصل «هدف بر روش»:
- **اصل:** آیا نقد به هدفی از هویت (`docs/ux/identity.md`) یا مخاطب (`docs/ux/audience.md`) اشاره می‌کند؟ اگر نه، فقط سلیقه است.
- **استاندارد:** آیا کف قابل‌سنجش (WCAG 2.2، کنتراست، اندازهٔ هدف لمسی، RTL) را نقض می‌کند؟ اگر بله، بدون بحث رفع می‌شود و دیگر «نقد طراحی» نیست؛ ابزار `bun run screens` بیشترشان را خودکار می‌سنجد.
- **روش رایج:** اگر نقد فقط روش دیگری پیشنهاد می‌کند، با دست‌کم دو گزینه در `docs/ui-audit.md` مقایسه شود.

باگ‌های واقعی رابط از همان ممیزی (UX-01، UX-04، UX-08) در این دور رفع شدند؛ PR «ب».
