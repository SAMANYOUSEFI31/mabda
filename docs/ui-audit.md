# ممیزی UX — مبدأ

روش: `bun run screens` (۳۹۰ و ۱۲۸۰، همهٔ نماها) + بازبینی چشمی اسکرین‌شات‌ها. هر ردیف: ایراد ← علت ← چه شد. ستون «وضعیت» در پایان هر فاز به‌روز می‌شود.
