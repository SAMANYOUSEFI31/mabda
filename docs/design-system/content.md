# لحن و متن رابط

متن بخشی از طراحی است. هر واژهٔ رابط یا اطلاعات می‌دهد یا کاری را نام می‌برد.

## صدا

دقیق، کوتاه، محترمانه. مثل همکار باتجربه‌ای که وقتت را نمی‌گیرد.

| هست | نیست |
| --- | --- |
| «تو» | «شما» (رسمی و دور) یا «ما» به‌جای محصول |
| نوشتار رسمیِ ساده: «می‌شود»، «است» | محاوره: «می‌شه»، «هست که» |
| جملهٔ کامل و کوتاه | تلگرافی یا ادبی |
| مشخص: «۳ خروجی قدیمی می‌شوند» | مبهم: «ممکن است بر برخی موارد اثر بگذارد» |
| آرام | هیجان («عالی!»، «تبریک!»)، علامت تعجب، شکلک |
| خنثی نسبت به کاربر | سرزنش («اشتباه وارد کردی») یا چاپلوسی |

محصول خودش را «من» یا «ما» نمی‌نامد. اگر لازم شد: «مبدأ».

لحن با موقعیت کمی جابه‌جا می‌شود، صدا نه: در خطا آرام‌تر و مشخص‌تر، در تأییدِ حذف جدی‌تر، در حالت خالی راهنماتر.

## قاعده‌های نوشتن

1. **اول مهم‌ترین واژه.** «حذف «قیمت اشتراک»؟» نه «آیا مطمئنی که می‌خواهی…».
2. **دکمه = فعل + (چیز).** «افزودن»، «حذف دائمی»، «به‌روز کردن». هیچ‌وقت «بله»، «باشه»، «تأیید» برای کاری که نام دارد.
3. **عنوان نقطه ندارد؛ جمله دارد.**
4. **یک مفهوم، یک واژه** (واژه‌نامهٔ پایین). مترادف برای تنوع ممنوع.
5. **عدد با رقم** («۳ خروجی»)، مگر اول جمله.
6. **نام چیزها در «گیومه».**
7. **بدون اصطلاح فنی:** نه «Object»، «Context»، «Node»، «sync»، «token» در رابط.
8. **کوتاه:** برچسب دکمه تا ۳ واژه؛ عنوان دیالوگ تا ۶؛ پیام گذرا یک جمله؛ توضیح حالت خالی تا دو جمله.
9. **خطا:** چه شد + چه کار کن. بدون «متأسفانه»، بدون «لطفاً» پشت‌سرهم.
10. **«…»** فقط برای کاری که پیش از انجام چیز دیگری می‌پرسد («حذف دائمی…») و برای متن کوتاه‌شده.

| بستن بی‌تغییر | **انصراف** | لغو، بی‌خیال |

واژه‌های ممنوع در `src/ui/bannedWords.json` اجبار می‌شوند؛ این جدول باید به آن فایل اضافه شود.

واژه‌هایی که رابط را «سازمانی» می‌کنند و به کار نمی‌روند: دارایی، ذی‌نفع، جریان کاری، داشبورد، پنل مدیریت، بهره‌وری، سازمان.

## دسترس‌پذیری متن

- هر دکمهٔ آیکنی نام خواندنی دارد که کار را می‌گوید («بستن»، «بیشتر برای «قیمت اشتراک»»).
- متن پیوند بیرون از بافت هم معنا دارد («دیدن ۳ خروجی»، نه «اینجا»).
- زبان صفحه `fa`؛ تکهٔ لاتین `lang="en"` و `dir="ltr"`.
- هیچ معنایی فقط با رنگ یا جا («دکمهٔ سبز»، «سمت چپ») گفته نمی‌شود.
