# چیدمان، فاصله و ریسپانسیو

## فاصله

شبکهٔ ۴. فقط این پله‌ها:

| توکن | مقدار | کاربرد معمول |
| --- | --- | --- |
| `space-1` | ۴ | بین آیکن و متنِ چسبیده، پدینگ منو |
| `space-2` | ۸ | بین دکمه‌ها، بین برچسب و فیلد |
| `space-3` | ۱۲ | پدینگ ردیف، بین آیکن و برچسب ناوبری |
| `space-4` | ۱۶ | پدینگ کناری گوشی، بین فیلدهای فرم |
| `space-5` | ۲۰ | پدینگ برگه |
| `space-6` | ۲۴ | پدینگ دیالوگ و کارت، بین موردهای کوتاه |
| `space-8` | ۳۲ | بین موردهای متن، پدینگ کناری دسکتاپ |
| `space-10` | ۴۰ | بین بخش‌های یک صفحه |
| `space-12` | ۴۸ | فاصلهٔ متن و حاشیه |
| `space-16` | ۶۴ | انتهای صفحه |
| `space-20`، `space-24` | ۸۰، ۹۶ | فقط صفحهٔ معرفی |

قاعدهٔ نزدیکی: فاصلهٔ درون یک گروه همیشه کمتر از فاصلهٔ میان دو گروه است، دست‌کم یک پله.

## نقطه‌های شکست

| نام | از پهنای | دستگاه نمونه |
| --- | --- | --- |
| پایه | ۰ | گوشی (طراحی از ۳۲۰؛ مرجع ۳۹۰) |
| `sm` | ۶۰۰ | گوشی بزرگ افقی، تبلت کوچک |
| `md` | ۷۶۸ | تبلت عمودی |
| `lg` | ۱۰۲۴ | تبلت افقی، لپ‌تاپ کوچک |
| `xl` | ۱۲۸۰ | لپ‌تاپ |
| `2xl` | ۱۵۳۶ | نمایشگر بزرگ |

نقطهٔ شکست فقط دربارهٔ **جا** است. دربارهٔ **ورودی** از پرسش‌های خودش استفاده می‌شود: `pointer: coarse` برای اندازهٔ هدف، `hover: hover` برای چیزهایی که با نشانگر پیدا می‌شوند. تبلتِ با صفحه‌کلید و لپ‌تاپِ لمسی هر دو درست کار می‌کنند.

## رفتار در هر پهنا

| | زیر ۷۶۸ | ۷۶۸ تا ۱۰۲۳ | ۱۰۲۴ تا ۱۲۷۹ | ۱۲۸۰ به بالا |
| --- | --- | --- | --- | --- |
| ناوبری اصلی | نوار پایین | نوار باریک (۶۴) | نوار باریک؛ باز شدن مجاز | نوار کناری باز (۲۶۴) |
| باز کردن نوار کناری | ندارد | روی محتوا می‌آید (کشو) | محتوا را کنار می‌زند | محتوا را کنار می‌زند |
| حاشیه | زیر هر مورد | زیر هر مورد | زیر هر مورد | ستون کناری اگر ظرف محتوا ≥ ۱۰۰۰ (پایین) |
| پنل جزئیات | برگهٔ پایین | روی محتوا، از لبهٔ پایانی | روی محتوا | کنار محتوا (اگر جا هست) |
| دیالوگ | برگهٔ پایین | وسط صفحه | وسط صفحه | وسط صفحه |
| منو | برگهٔ کوتاه اگر بیش از ۵ ردیف | منوی شناور | منوی شناور | منوی شناور |
| پدینگ کناری صفحه | ۱۶ | ۲۴ | ۳۲ | ۳۲ |
| کارهای هر ردیف | همیشه پیدا (یک «بیشتر») | همیشه پیدا | با نشانگر یا فوکوس | با نشانگر یا فوکوس |
| جدول | فهرست دوخطی | جدول | جدول | جدول |
| دکمهٔ «افزودن» | وسط نوار پایین | بالای صفحه | بالای صفحه | بالای صفحه |

قاعده‌های کلی:

- **هیچ اسکرول افقی** در هیچ پهنایی از ۳۲۰ به بالا، جز درون جدول پهن و بلوک کد که اسکرول خودشان را دارند.
- محتوا بالای ۱۱۲۰ پهن‌تر نمی‌شود؛ جای اضافه در دو طرف می‌ماند. متن هیچ‌وقت از ۶۸۰ پهن‌تر نمی‌شود.
- ارتفاع با `dvh` حساب می‌شود (نه `vh`) تا نوار مرورگر گوشی چیزی را نبُرد.
- ناحیهٔ امن دستگاه (`env(safe-area-inset-*)`) به پدینگ نوار بالا، نوار پایین و پای برگه اضافه می‌شود.
- با باز شدن صفحه‌کلید گوشی، فیلد فعال و دکمهٔ اصلی برگه دیده می‌مانند.
- صفحه تا بزرگ‌نمایی ۲۰۰٪ و «فاصلهٔ متن» بیشتر بدون بریدگی کار می‌کند؛ در ۴۰۰٪ به چیدمان گوشی می‌رود.
- افقی‌شدن گوشی چیدمان را به `sm` می‌برد؛ نوار پایین می‌ماند.

## ستون حاشیه: با پهنای ظرف، نه پهنای صفحه

حساب: متن (۶۰۰ تا ۶۸۰) + فاصله (۴۸) + حاشیه (۲۸۸) + پدینگ دو طرف (۲ × ۳۲) = **۱۰۰۰ تا ۱۰۸۰**. پس:

- ستون حاشیه با **container query** روی ظرف محتوا روشن می‌شود: از ۱۰۰۰ به بالا کنار متن، زیر آن زیر هر مورد. پهنای صفحه تعیین‌کننده نیست، چون نوار کناری (۶۴ تا ۳۶۰) و پنل جزئیات از آن کم می‌کنند.
- بین ۱۰۰۰ و ۱۰۸۰، فقط ستون متن جمع می‌شود (تا ۶۰۰)؛ حاشیه همیشه ۲۸۸ است.
- نمونه‌ها: ۱۲۸۰ با نوار باز ۲۶۴ ← ظرف ۱۰۱۶ ← حاشیه کنار متن، متن ۶۱۶. ۱۲۸۰ با نوار ۳۶۰ ← ظرف ۹۲۰ ← حاشیه زیر مورد. ۱۰۲۴ با ریل ← ظرف ۹۶۰ ← زیر مورد. ۱۴۴۰ با نوار باز ← ظرف ۱۱۷۶ ← کنار، متن ۶۸۰.
- نمای سند سقف ۱۰۸۰ دارد؛ `content-max` (۱۱۲۰) سقف نماهای شبکه و جدول است.

## ساختار صفحه

```
┌──────────────────────────────────────────────┬───────────┐
│ عنوان صفحه                  [نما] [افزودن]   │  نوار     │
│ یک خط خلاصه                                  │  کناری    │
│                                              │           │
│  حاشیه (۲۸۸)      متن (تا ۶۸۰)               │           │
│  ◇ فکر مرتبط      ◆ عنوان مورد               │           │
│                     متن حقیقت …              │           │
│                     نوع · نسخه · منبع        │           │
└──────────────────────────────────────────────┴───────────┘
```

- سرصفحه: مسیر (اگر عمق بیش از یک است)، `title-1`، یک خط خلاصه. کارها در لبهٔ پایانی سرصفحه؛ دکمهٔ اصلی آخرین است.
- بدنه: ستون متن از لبهٔ آغازین شروع می‌شود (وسط‌چین نیست)؛ چشم همیشه از یک جا شروع می‌کند.
- عمق سلسله‌مراتب دیداری حداکثر سه: صفحه، بخش، مورد. کارت‌درکارت ممنوع.

## تراکم

یک تراکم داریم («آرام»). حالت فشرده عرضه نمی‌شود؛ جدول‌ها و فهرست‌های بلند با ارتفاع ردیف ۴۰ به‌جای ۴۸ خودشان فشرده‌ترند.
