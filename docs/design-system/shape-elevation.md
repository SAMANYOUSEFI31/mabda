# شکل، بلندی و شفافیت

## گوشه

| توکن | مقدار | کجا |
| --- | --- | --- |
| `radius-xs` | ۴ | نشان، تیک، برجسته‌سازی متن |
| `radius-sm` | ۶ | راهنمای ابزار، کلید میان‌بر |
| `radius-md` | ۸ | دکمه، فیلد، ردیف، گزینهٔ منو |
| `radius-lg` | ۱۲ | کارت، منو، پیام، کاشی نوار پایین |
| `radius-xl` | ۱۶ | دیالوگ |
| `radius-2xl` | ۲۰ | گوشه‌های بالای برگه |
| `radius-full` | ۹۹۹ | آواتار، کلید، chip |

- **هم‌مرکزی:** گوشهٔ بیرونی = گوشهٔ درونی + فاصلهٔ میانشان. (منو ۱۲ با پدینگ ۴ و گزینهٔ ۸.)
- گوشه هیچ‌وقت معنای وضعیت ندارد.
- عنصری که به لبهٔ صفحه چسبیده، در آن لبه گوشه ندارد.

## خط

- ضخامت ۱. خط جداکننده `border-subtle`، لبهٔ برگ `border-default`، لبهٔ فیلد `border-input` (تنها خطی که باید ۳ به ۱ باشد).
- **خط‌چین فقط «جای خالی» است.**
- خط رنگی کنار کارت (نوار وضعیت) نداریم.
- جداکننده وقتی فاصله کافی است لازم نیست؛ اول فاصله، بعد خط.

## بلندی

بلندی با سه چیز گفته می‌شود، به این ترتیب: رنگ سطح، خط لبه، و در آخر سایه.

| سطح | روی چه | سایه |
| --- | --- | --- |
| میز (`surface-page`) | | ندارد |
| برگ: کارت، فیلد (`surface-raised`) | میز | `shadow-1` یا فقط خط |
| شناور: منو، تقویم، پیام گذرا (`surface-overlay`) | هر چیز | `shadow-2` |
| دیالوگ و برگه (`surface-overlay`) | پرده | `shadow-3` |

- سه سایه، نه بیشتر. سایه‌ها خنثی‌اند (رنگ جوهر با شفافیت کم) و در شب تقریباً دیده نمی‌شوند؛ آنجا روشن‌تر شدن سطح کار را می‌کند.
- کارتِ معمولی سایه ندارد. سایه یعنی «این روی چیز دیگری است و می‌رود».

## شفافیت: «کاغذ کالک»

**«شیشهٔ مایع» نداریم.** متن فارسی روی زمینهٔ متغیر خوانایی‌اش را از دست می‌دهد و با قول «روشنی» نمی‌خواند. فقط یک استفادهٔ محدود هست:

| | |
| --- | --- |
| کجا | نوارهایی که محتوا از زیرشان رد می‌شود: نوار بالای گوشی، نوار پایین، پای دکمه‌های برگه و دیالوگ، سرستون چسبان جدول |
| کِی | فقط وقتی واقعاً محتوایی زیر نوار است. در ابتدا یا انتهای اسکرول، نوار مات و بی‌خط است. |
| رنگ | رنگ همان صفحه با پوشش **۸۶٪ در روز** و **۸۰٪ در شب** (`surface-bar`) |
| محو | **۱۶ پیکسل** (`blur-bar`) |
| اشباع | **۱٫۴ برابر** (`saturate-bar`) تا رنگ‌های زیر نوار خاکستری نشوند |
| لبه | خط `border-subtle` در لبهٔ رو به محتوا، فقط در حالت شفاف |
| کنتراست | متن روی نوار با بدترین محتوای زیرش دست‌کم ۴٫۵ به ۱ (اکنون ۵٫۳ برای متن ثانویه، ۸٫۷ برای متن اصلی) |

هیچ‌وقت شفاف نیستند: منو، دیالوگ، برگه (بدنه)، کارت، پیام گذرا، نوار کناری. متن روی آن‌هاست و باید بی‌قید خوانده شود.

پرده (پشت دیالوگ و برگه): جوهر ۴۰٪ در روز، سیاه ۶۰٪ در شب، **بدون محو**. محوکردن کل صفحه سنگین است و حس «گم‌شدن» می‌دهد.

جایگزین‌ها:

- «شفافیت کمتر» دستگاه (`prefers-reduced-transparency`) یا «کنتراست بیشتر» (`prefers-contrast: more`): نوارها مات می‌شوند و خط لبه پررنگ‌تر.
- مرورگر بدون `backdrop-filter`: پوشش ۹۶٪.

## ترتیب لایه‌ها

| توکن | مقدار | |
| --- | --- | --- |
| `z-base` | ۰ | |
| `z-raised` | ۱۰ | دستگیرهٔ تغییر اندازه، سرستون چسبان |
| `z-bar` | ۲۰۰ | نوار بالا و پایین |
| `z-dropdown` | ۳۰۰ | منو، تقویم |
| `z-scrim` | ۴۰۰ | پرده |
| `z-dialog` | ۵۰۰ | دیالوگ، برگه، کشوی نوار کناری |
| `z-popover` | ۶۰۰ | منوی باز شده از درون دیالوگ |
| `z-toast` | ۷۰۰ | پیام گذرا |
| `z-tooltip` | ۸۰۰ | راهنمای ابزار |
| `z-skip` | ۹۰۰ | پیوند «پرش به محتوا» |

هیچ `z-index` خام در کد. هر چیز شناور در لایهٔ رویی سند (portal) ساخته می‌شود، نه درون ظرفی که اسکرول یا بُرش دارد؛ این همان چیزی است که منوی حساب را از بریده‌شدن نجات می‌دهد.

## حالت‌های کنترل

| حالت | نمایش |
| --- | --- |
| نشانگر | `bg-hover` (یا یک پله تیره‌تر برای دکمهٔ پر) |
| فشرده | `bg-pressed` و کوچک‌شدن ۲٪ (فقط دکمه) |
| فوکوس صفحه‌کلید | حلقهٔ ۲ پیکسلی `border-focus` با فاصلهٔ ۲ از لبه. هیچ‌وقت حذف نمی‌شود. با کلیک موس نشان داده نمی‌شود. |
| انتخاب‌شده | `bg-selected` + متن اصلی + وزن ۶۰۰ |
| غیرفعال | شفافیت ۴۰٪، بدون نشانگر؛ دلیلش همیشه نزدیکش نوشته شده |
| در حال کار | چرخهٔ کوچک به‌جای آیکن، برچسب می‌ماند، پهنا عوض نمی‌شود |
| در حال کشیدن | شفافیت ۶۰٪ و `shadow-2` |
