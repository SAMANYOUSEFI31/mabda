# برنامهٔ اجرا

برای رشته‌ای که PR #51 را می‌سازد. ترتیب مهم است: هر گام روی گام قبل می‌نشیند. هر ردیف «معیار پذیرش» دارد؛ بدون آن، انجام‌شده حساب نمی‌شود.

**مبنا:** ممیزی PR #51 (<https://claude.ai/artifact/HBWbhHp6i585LqqmXUxtQr>) و بررسی اپ در حال اجرا (۳۹۰ و ۱۲۸۰، روز و شب). **مرجع دیداری:** نسخهٔ قابل‌مرور (<https://claude.ai/artifact/6N3sLRhVzDpEHoBgUBbzMj>)؛ CSS مرجع هر جزء همان‌جاست (`components/bundle.css`) و فقط از توکن استفاده می‌کند.

**ادغام اسناد:** این PR فقط سند است. اگر با PR #51 در `docs/ux/identity.md` و `docs/design-system/{README,components,tokens,typography}.md` برخورد داشت، نسخهٔ این PR می‌ماند. `docs/ux/meaning-map.md` و `docs/ux/interaction-grammar.md` (از PR #51) می‌مانند ولی باید با زبان نقطه هم‌خوان شوند (گام ۲). در `CLAUDE.md` هر دو تغییر لازم است: خط خلاصه و مراجع از این PR، بخش سیستم طراحی و قانون ۲ از PR #51.
