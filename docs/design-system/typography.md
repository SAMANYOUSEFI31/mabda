# تایپوگرافی

## خط

- **وزیرمتن**، نسخهٔ متغیر، یک فایل (۱۱۱ کیلوبایت، woff2)، میزبانی‌شده در خود اپ. پروانهٔ OFL.
- وزن‌ها: ۴۰۰ (متن)، ۵۰۰ (برچسب و دکمه)، ۶۰۰ (عنوان و تأکید)، ۷۰۰ (عنوان بزرگ). وزن دیگری به کار نمی‌رود.
- کد و شناسه: پشتهٔ تک‌فاصلهٔ سیستم (`ui-monospace, "SF Mono", "Cascadia Code", Consolas, monospace`).
- پشتیبان پیش از رسیدن خط: `"Vazirmatn", system-ui, "Segoe UI", Tahoma, sans-serif` با `font-display: swap` و `size-adjust` تا متن نپرد.

### چرا وزیرمتن

روی یک صفحهٔ متن بلند واقعی (روز و شب، ۱۴ تا ۲۰) با استعداد، مرکزی، نوتو نسخ، نوتو سنس عربی و IBM Plex Arabic مقایسه شد:

| معیار | نتیجه |
| --- | --- |
| خوانایی در ۱۴ و ۱۶ | وزیرمتن و استعداد بهترین؛ نسخ‌ها در ۱۴ ریز و لرزان |
| رقم فارسی، «٬» و «٫» و «٪» | وزیرمتن کامل و هم‌عرض؛ Plex رقم عربی (٤٥٦) می‌دهد |
| لاتین همراه | وزیرمتن لاتین هم‌وزن دارد؛ بقیه به خط دوم نیاز دارند |
| وزن‌های میانی | متغیر، ۱۰۰ تا ۹۰۰ |
| حجم | یک فایل |

استعداد شخصیت بیشتری دارد ولی در متن بلند خسته‌کننده‌تر بود. هویت Mabda از نظام تایپ می‌آید، نه از قلم کم‌یاب.

## مقیاس

واحد `rem` است (۱۶ = ۱rem) تا با تنظیم اندازهٔ متن مرورگر بزرگ شود. اعداد زیر در ۱۰۰٪ هستند: اندازه / فاصلهٔ خط / وزن.

| نام | مقدار | کاربرد |
| --- | --- | --- |
| `display` | ۳۶ / ۵۲ / ۷۰۰ | فقط صفحهٔ ورود و معرفی |
| `title-1` | ۲۸ / ۴۲ / ۷۰۰ | عنوان صفحه؛ یک بار در هر نما |
| `title-2` | ۲۲ / ۳۴ / ۶۰۰ | عنوان بخش، عنوان دیالوگ |
| `title-3` | ۱۸ / ۳۰ / ۶۰۰ | عنوان زیربخش، عنوان حالت خالی |
| `headline` | ۱۶ / ۲۶ / ۶۰۰ | عنوان هر مورد در متن |
| `body-reading` | ۱۷ / ۳۲ / ۴۰۰ | متن حقیقت‌ها (خواندن طولانی) |
| `body` | ۱۶ / ۲۸ / ۴۰۰ | متن عمومی، ردیف فهرست |
| `body-sm` | ۱۴ / ۲۴ / ۴۰۰ | متن ثانویه، حاشیه، ردپا |
| `caption` | ۱۲ / ۲۰ / ۴۰۰ | مهر زمان، راهنمای زیر فیلد |
| `label-lg` | ۱۶ / ۲۴ / ۵۰۰ | دکمهٔ بزرگ، گزینهٔ فهرست |
| `label` | ۱۴ / ۲۰ / ۵۰۰ | دکمه، برچسب فیلد، ناوبری |
| `label-sm` | ۱۲ / ۱۸ / ۵۰۰ | نشان، برچسب نوار پایین، سرستون جدول |
| `numeric` | ۲۸ / ۴۰ / ۶۰۰ | عدد شاخص |
| `code` | ۱۳ / ۲۲ / ۴۰۰ | کد، شناسه، میان‌بر |

قاعده‌ها:

- کوچک‌ترین متن ۱۲ است. متن ۱۲ هیچ‌وقت جمله نیست.
- فاصلهٔ خط فارسی بلندتر از لاتین است (نسبت ۱٫۶ تا ۱٫۹)؛ اعراب و سرکش نباید به خط بالا بخورند.
- در گوشی مقیاس عوض نمی‌شود، جز `title-1` که ۲۴ / ۳۶ می‌شود.
- در هر نما حداکثر چهار اندازه.
- فاصلهٔ حروف، حروف کج (italic) و حروف بزرگ برای فارسی به کار نمی‌رود. تأکید با وزن ۶۰۰ است.
- کشیدگی (ـ) برای هم‌ترازی ممنوع.
- `text-wrap: balance` برای عنوان‌ها، `pretty` برای متن. هیچ عنوانی با یک واژهٔ تنها در سطر آخر نمی‌ماند.
- ستون خواندن حداکثر ۶۸۰ (حدود ۷۰ تا ۸۰ نویسه). متن راست‌چین؛ هم‌تراز دوطرفه نه.

## دوجهته

- جهت صفحه `rtl` است. هر تکهٔ لاتین درون متن فارسی در `<bdi>` یا با `dir="ltr"` جدا می‌شود تا نقطه و پرانتز جابه‌جا نشود.
- ورودی‌ای که ممکن است لاتین باشد (ایمیل، نشانی) `dir="auto"` دارد.
- نقل‌قول «گیومه» است، نه "…".
- نیم‌فاصله درست نوشته می‌شود: «می‌شود»، «خروجی‌ها»، «به‌روز».
- سه‌نقطه یک نویسه است «…»، نه سه نقطه.

## نبایدها

- خط دوم برای «شخصیت».
- متن خاکستری روی خاکستری برای «آرام‌تر» کردن؛ آرامش از فاصله می‌آید.
- عنوان با وزن ۷۰۰ پایین‌تر از `title-1`.
- اندازهٔ دلخواه بیرون از مقیاس.
