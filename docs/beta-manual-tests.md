# جدول آزمون دستی (افراد آزمون)

آنچه تست خودکار نمی‌تواند روی دستگاه واقعی ببیند. هر نفر روی گوشی یا لپ‌تاپ خودش انجام می‌دهد و نتیجه را (درست / مشکل + توضیح کوتاه) به صاحب محصول می‌گوید.

| # | کار | چه باید ببینی |
|---|---|---|
| ۱ | لینک شخصی‌ات را باز کن | بدون رمز وارد می‌شوی؛ نامت در منوی حساب است؛ لینک از نوار نشانی پاک شده |
| ۲ | مرورگر را ببند و فردا دوباره باز کن | هنوز وارد هستی و داده‌ات سر جایش است |
| ۳ | فضای نمونه را باز کن، چیزی اضافه و ویرایش کن | تغییر بعد از تازه‌کردن صفحه می‌ماند |
| ۴ | **بوم با لمس (BETA-04):** در «منبع» نمای بوم را باز کن؛ با یک انگشت جابه‌جا کن، با دو انگشت بزرگ و کوچک کن، یک کارت را بکش | صفحه به‌جای بوم نمی‌لغزد؛ کارت زیر انگشت می‌ماند؛ هیچ کاری ناخواسته انجام نمی‌شود |
| ۵ | یک تاریخ انتخاب کن (مثلاً تاریخ انقضا) | همان روزی ذخیره می‌شود که انتخاب کردی |
| ۶ | «حساب و داده‌ها» ← «پشتیبان کامل»، بعد «برگرداندن از فایل پشتیبان…» با همان فایل | یک فضای تازه «… (برگردانده‌شده)» با همهٔ داده‌ها؛ فضای اصلی دست‌نخورده |
| ۷ | اینترنت را قطع کن و کاری انجام بده | پیام روشن و «دوباره»؛ صفحهٔ سفید نه |
| ۸ | «خروج از این دستگاه» | به صفحهٔ ورود برمی‌گردی؛ با لینک دوباره وارد می‌شوی |
