# تصمیم‌های v3.1

این سند **مرجع بالاتر از PRD قدیمی** (`docs/PRD.md`) است. هر جا با PRD تناقض داشت، این سند ملاک است.

## ۱. Auto واقعی
- router سطح مدل (cheap / balanced / frontier)، effort، الگو (single / cascade / critique) و بازهٔ طول خروجی را انتخاب می‌کند.
- در صورت نیاز تا frontier بالا می‌رود (اعتبار قبل از اجرا نشان داده می‌شود).
- هیچ پاسخ ساختگی یا از پیش‌نوشته جای پاسخ AI نمایش داده نمی‌شود. در خطا: پیام روشن + تلاش دوباره.

## ۲. لایهٔ تصمیم (Decision Layer)
- یک رابط واحد برای قضاوت‌های بسته: انتخاب از گزینه‌ها + احتمال.
- پیاده‌سازی فعلی: مدل ارزان با خروجی JSON. پشت همین رابط قابل جایگزینی است.
- کاربردها: router، پیش‌غربال تناقض، ابهام در Gap، تشخیص پیشنهاد به‌روزرسانی، چک گاردریل.

## ۳. اصالت و اثر تغییر (Lineage & Impact)
- هر Asset نسخهٔ Contextهایی را که در ساختش استفاده شده ذخیره می‌کند.
- تغییر Context، Assetهای وابسته را «قدیمی» علامت می‌زند (با دلیل).

## ۴. ساختار سه‌لایه
- **گره‌های سیستمی:** قابل تغییر نام، غیرقابل حذف.
- **گره‌های کاربر:** آزاد.
- **یادداشت آزاد:** به مدل تزریق نمی‌شود.
- گفتگو به یک گره محدود است.

## ۵. Context Coach
- با مدل متعادل (balanced) در onboarding و تعریف گره.

## ۶. فایل
- یک‌بار پردازش: خلاصه، Object پیشنهادی، قطعه.
- فقط قطعه‌های مرتبط تزریق می‌شوند.
- سهمیهٔ ماهانهٔ رایگان؛ بیشتر از آن ۲ اعتبار به ازای هر ۲۰ هزار توکن.

## ۷. طول خروجی
- برای هر نوع خروجی یک بازهٔ پیش‌فرض.
- ضریب ۱٫۵ یا ۲ برای خروجی بلندتر.
- نمایش قبل از اجرا.

## ۸. ویرایشگر spec
- فهرست‌های نامحدود.
- وابستگی گرافی بین خروجی‌ها.
- گاردریل.

## ۹. سیستم طراحی
- فقط توکن‌های معنایی بوشیدو (`public/ds`)؛ هیچ مقدار hex.

## ۱۰. آزمون تمایز
- مقایسهٔ کور با «دستیار عمومی + skill + حافظه» روی ۵ کار.
- کمتر از ۳ برد = توقف یا چرخش.

## قالب خروجی و ترتیب لایه‌ها
- **خروجی‌ها:** پاسخ مدل = JSON از بلوک‌ها `{id, kind, markdown, proposal?}`؛ نمایش و ذخیرهٔ دارایی‌ها Markdown.
- **لایهٔ Context اول:** MVP با MCP + «بستهٔ Context» + BYOK. اشتراک برای ساختار و موتورها؛ AI مدیریت‌شده با کردیت پشت feature flag و بعد از آزمون تمایز.
- **موتورها:** قانون دقیق = کد؛ قضاوت معنایی = لایهٔ تصمیم با مدل ارزان.
