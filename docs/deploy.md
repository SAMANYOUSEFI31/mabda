# نسخهٔ آنلاین (Deploy)

هدف: همان اپ ریسپانسیو، با یک نشانی، روی هر دستگاه (گوشی، تبلت، لپ‌تاپ)؛ با هر merge به `main` خودکار به‌روز شود.

- **میزبان:** Render (Docker، طبق `render.yaml` و `Dockerfile`). روش است نه اصل؛ تا وقتی هدف را بهتر از جایگزین‌ها برآورده کند.
- **امنیت (اصل):** Mabda ورود و حساب ندارد، پس سرور production بدون `MABDA_ACCESS_PASSWORD` بالا نمی‌آید (`server/access.ts`، با تست). رمز را Render خودش می‌سازد.
- **داده:** پلن رایگان دیسک ماندگار ندارد؛ پایگاه داده با هر استقرار/خواب خالی می‌شود. برای دیدن محصول کافی است؛ برای نگه‌داشتن داده باید دیسک (پولی) و پشتیبان‌گیری اضافه شود.
- **بررسی سلامت:** `/healthz` (بدون رمز، فقط «ok»).
- **اجرا:** `tsx server.ts` (دستور `node server.ts` روی Node با کد فعلی کار نمی‌کند: پارامتر-پراپرتی TypeScript).
