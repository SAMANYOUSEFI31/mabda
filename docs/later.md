# بعداً (ایده‌ها و کارهای عمداً کنار گذاشته‌شده)

پیش از ساختن هر قابلیت تازه این فهرست را بخوان: شاید پیش‌تر دربارهٔ آن تصمیم گرفته شده (پارک، ردّ با دلیل، یا منتظر کاربر).

**وضعیت‌ها:** `پارک‌شده` = ایدهٔ خوب، نوبتش نرسیده · `تصمیم باز` = تصمیمش با کاربر است، کد نزن · `ردشده` = دلیل دارد، دوباره بحثش نکن مگر دلیل عوض شود · `کار کاربر` = کد نیست.

## تصمیم باز (با کاربر)

| چیست | چرا الان نه | چه وقت بازبینی | وضعیت |
| --- | --- | --- | --- |
| **شاخص‌ها و KPI** (جا در منو، کارت خانه، افزودن و ثبت عدد) | کاربر می‌خواهد خودش رویش فکر کند؛ هر پرامپت «خارج از دامنه» نوشته | وقتی کاربر تصمیمش را گفت | تصمیم باز |
| **بازار ایران:** ارائه‌دهندهٔ AI قابل استفاده از ایران، پرداخت ریالی، میزبانی، کار با اینترنت ناپایدار | تصمیم کسب‌وکاری است، نه رابط | پیش از اولین عرضهٔ واقعی | تصمیم باز |
| **هوش مصنوعی داخلی مبدأ و مدل کسب‌وکار:** وجود یا عدم وجود AI داخلی در Mabda، دامنه و نقش آن (مشورتی)، و جایگاه آن در پلن‌ها و درآمدزایی | نیازمند تصمیم‌گیری محصولی و بازخورد واقعی کاربران است؛ حذف MCP و BYOK قطعی شده اما سرنوشت AI داخلی باز است | در بازنگری استراتژی پلن‌ها و عرضه | تصمیم باز |

## تصمیم P5 — حذف یکپارچه‌سازی و کلیدهای کاربر از MVP

| محدوده | تصمیم |
| --- | --- |
| اتصال MCP، توکن‌ها، endpointها، UI مدیریت اتصال و SDK | از MVP حذف شد؛ migration v22 توکن‌های فعال را باطل می‌کند و رکوردهای تاریخی را نگه می‌دارد. |
| BYOK، vault کلید، ورود کلید، انتخاب provider/model و هزینهٔ شخصی | از MVP حذف شد؛ فایل‌های vault قدیمی در شروع سرور به‌شکل محدود پاک می‌شوند؛ زیرساخت اجرایی برای بعد نگه داشته نمی‌شود. |
| Context pack، واردکردن/چسباندن عمومی، منشأ و تأیید Proposed | باقی می‌مانند چون مستقل از MCP و BYOK کار دارند؛ محتوای بیرونی هرگز مستقیم Truth نمی‌شود. |
| رکوردهای تاریخی `mcp` و `byok` | فقط سازگاری خواندن/نمایش و حسابداری درست دادهٔ قدیمی؛ هیچ مسیر نوشتن فعال ندارند. |
| ارائه‌دهندهٔ داخلی و دسترسی بازار ایران | تصمیم عملیاتی/بازاریِ پلتفرم است؛ کاربر provider یا اعتبارنامه انتخاب نمی‌کند. |

**رد شد:** نگه‌داشتن دکمه‌ها و backend «خاموش برای بعداً» (سطح حمله و نگهداری بی‌دلیل)، و حذف منشأ/بسته‌ها (آسیب به تاریخچه و ورود عمومی).

*مرز هوش مصنوعی در MVP:*
- حذف MCP و BYOK تصمیم فعلی و قطعی MVP است.
- وجود یا نبود AI داخلی Mabda، دامنه و نقش آن، قابلیت‌های چندوجهی (Multimodal) و حضور آن در پلن‌ها و مدل درآمدی، یک تصمیم باز (Open Decision) محصولی است و تصمیم ردشدهٔ دائمی تلقی نمی‌شود.
- در این مرحله هیچ زیرساخت تازهٔ AI ساخته نمی‌شود و قابلیت فعالی نیز حذف نمی‌گردد.
