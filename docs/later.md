# بعداً (ایده‌ها و کارهای عمداً کنار گذاشته‌شده)

پیش از ساختن هر قابلیت تازه این فهرست را بخوان: شاید پیش‌تر دربارهٔ آن تصمیم گرفته شده (پارک، ردّ با دلیل، یا منتظر کاربر).

**وضعیت‌ها:** `پارک‌شده` = ایدهٔ خوب، نوبتش نرسیده · `تصمیم باز` = تصمیمش با کاربر است، کد نزن · `ردشده` = دلیل دارد، دوباره بحثش نکن مگر دلیل عوض شود · `کار کاربر` = کد نیست.

## تصمیم باز (با کاربر)

| چیست | چرا الان نه | چه وقت بازبینی | وضعیت |
| --- | --- | --- | --- |
| **شاخص‌ها و KPI** (جا در منو، کارت خانه، افزودن و ثبت عدد) | کاربر می‌خواهد خودش رویش فکر کند؛ هر پرامپت «خارج از دامنه» نوشته | وقتی کاربر تصمیمش را گفت | تصمیم باز |
| **بازار ایران:** ارائه‌دهندهٔ AI قابل استفاده از ایران، پرداخت ریالی، میزبانی، کار با اینترنت ناپایدار | تصمیم کسب‌وکاری است، نه رابط | پیش از اولین عرضهٔ واقعی | تصمیم باز |

## ردشده (با دلیل)

| چیست | دلیل |
| --- | --- |
| **ساخت خودکار رابطه از ساختار درخت** (همهٔ موارد زیربخش وابسته به همهٔ موارد بخش بالا؛ هم‌بخش‌ها هم‌زمان) | جای بخش اغلب برای پیدا کردن است؛ جابه‌جایی بی‌صدا منطق را عوض می‌کرد؛ n×m رابطه سیل needsReview می‌ساخت؛ هم‌بخش بودن هم‌زمانی نیست؛ رابطه ادعای گفته‌شده است. به‌جایش سه سرنخ در docs/spine.md |
| **تغییر اندازهٔ کادر بخش در بوم فکر** | کادر دور اعضایش است؛ جعبهٔ بزرگ‌تر از اعضا معنایی ندارد و با جابه‌جایی کارت‌ها درگیر می‌شود (`canvas-design.md`) |
| **ممنوع کردن چرخه در «وصل کن»** | spine می‌گوید دو تصمیمِ روی هم سوار «با هم تصمیم گرفته می‌شوند»؛ فقط خودوابستگی ممنوع است |
| **چند پیش‌نویس رقیب برای یک دانش** | نیازش با «گزینه‌های تصمیم باز» حل می‌شود |
| **`@` برای «روی چه اثر دارد»** | نحو تازه می‌خواهد و از جزئیات دانش قابل ویرایش است (`RelationPicker`) |
| **انتخاب چند بخش پراکنده برای یک دانش** | یک خانه برای هر دانش + overrides؛ برای چند بخش، اولین والد مشترک |
| **«موتور اعتبارسنجی» جدا برای پاسخ AI بیرونی** | مسیر پیشنهاد ← تأیید/پیش‌نویس و موتورهای تکراری و تناقض موجود کافی‌اند |
| **AI به‌عنوان مبنای نگاشت پاسخ AI بیرونی** | نگاشت فقط با نشانهٔ صریح و قاعده؛ AI مبنا نیست |
| **فیلد ساختاریافته برای «دربارهٔ» فکر** (migration) | `@«…»` در متن خط کافی و برگشت‌پذیر است |
